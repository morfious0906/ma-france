# Ma France

واجهة حديثة ثنائية اللغة لتعلّم الفرنسية، مبنية حول فكرة **«الدفتر الباريسي الحي»**. تستخدم التجربة العربية والفرنسية في رحلة واحدة، مع مسار دروس قصير واختبار تحديد مستوى ومتابعة محلية للتقدّم.

## التشغيل المحلي

يتطلب المشروع Node.js وpnpm. بعد تثبيت الحزم، شغّل:

```bash
pnpm dev
```

وللتحقق من النوع وبناء نسخة الإنتاج:

```bash
pnpm check
pnpm build
```

## ما الذي يتضمنه الإصدار

يتضمن الموقع صفحة تعريف تحريرية متجاوبة، تبديلًا عربيًا/فرنسيًا مع دعم RTL، وضع ألوان داكن، اختبار تحديد مستوى من ثلاث مراحل، لوحة دروس تفاعلية، تشغيلًا محليًا للنطق الفرنسي من المتصفح، تمرينًا قصيرًا مع تغذية راجعة، بطاقات مفردات، وحفظ التقدّم والنقاط على الجهاز عبر `localStorage`.

## الأصول البصرية

تعتمد الصور والرمز على مسارات أصول مُدارة داخل بيئة النشر الحالية. عند نقل المشروع إلى استضافة خارجية، يجب نقل هذه الأصول إلى مخزن الاستضافة نفسه وتحديث المسارات في `client/src/pages/Home.tsx`.
