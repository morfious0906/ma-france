# Ma France

منصة حديثة ثنائية اللغة لتعلّم الفرنسية، مبنية حول فكرة **«الدفتر الباريسي الحي»**. تجمع التجربة العربية والفرنسية في رحلة واحدة، مع حسابات مستخدمين ومزامنة تقدّم واختبار تحديد مستوى ودروس من A1 حتى C1.

## التشغيل المحلي

يتطلب المشروع Node.js وpnpm. بعد تثبيت الحزم، شغّل:

```bash
pnpm dev
```

وللتحقق من النوع وبناء نسخة الإنتاج:

```bash
pnpm check
pnpm build
```

## ما الذي يتضمنه الإصدار

يتضمن الموقع صفحة تعريف تحريرية متجاوبة، تبديلًا عربيًا/فرنسيًا مع دعم RTL، وضع ألوان داكن، اختبار تحديد مستوى من ثلاث مراحل مع تغذية راجعة، لوحة دروس تفاعلية، وحركات قصيرة للإجابات الصحيحة والخاطئة. يمتد المنهج من A1 إلى C1، مع مفردات مصنفة حسب الموضوع والمستوى.

تستخدم الحسابات المسجّلة مصادقة مدمجة ومزامنة تقدّم عبر قاعدة البيانات؛ حيث تُخزّن ملفات المتعلم وتقدم الدروس وإجابات التمارين ودفتر الكتابة ومراجعات المفردات. يبقى `localStorage` محصورًا في تفضيلات اللغة والمظهر ووضع التجربة غير المسجل.

## قاعدة البيانات والاختبارات

يتضمن المشروع ترحيلات Drizzle وجداول `learner_profiles` و`lesson_progress` و`exercise_answers` و`writing_entries` و`vocabulary_reviews`. شغّل الاختبارات عبر:

```bash
pnpm test
```

## الأصول البصرية

تعتمد الصور والرمز على مسارات أصول مُدارة داخل بيئة النشر الحالية. عند نقل المشروع إلى استضافة خارجية، يجب نقل هذه الأصول إلى مخزن الاستضافة نفسه وتحديث المسارات في `client/src/pages/Home.tsx`.
